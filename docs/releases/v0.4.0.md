# Switchyard v0.4.0

## Added

- Compact Electron navigation, project folders with shared working and
  coordination directories, flat agent chat lists, and live/waiting indicators.
- Image paste attachments, model selection with refresh and pricing/context
  details, Markdown transcripts, collapsed tool activity, and changed-file review.
- Optional development and Slack API toolpacks, loaded on demand and saved with
  sessions. Existing Codex/Claude skills remain reusable.
- Session data migration and stronger project/message isolation.

## Fixed

- Parked-agent wake-up, direct worker messaging, duplicate delivery/resume
  protection, Windows session writes, first-turn chat naming, and live transcripts.
- Provider reasoning/history compatibility, current model metadata, DeepSeek
  native image viewing, and oversized-context compaction fallback.
- Single-instance desktop focus, Windows installer CLI routing, keypad/CSI-u
  Enter, service command quoting, and managed-process identity checks.

## Installation and updating

`switchyard` starts the terminal CLI. `switchyard app` opens Electron; the Start
Menu shortcut also opens the desktop app. `switchyard-cli`, `d`, and `dsw` remain
terminal aliases.

The startup updater compares the installation's Git checkout with `origin/master`
and offers a fast-forward source update. Source runs restart onto updated code.
Compiled executables still require rebuilding or rerunning the installer; this
release does not add automatic binary/desktop replacement.

From PowerShell, rerun the installer if a rebuild is required:

```powershell
irm https://raw.githubusercontent.com/gaston1799/switchyard/master/install.ps1 | iex
```

The Windows archive contains CLI executables at the root and the Electron app
under `desktop/`. SHA-256 checksums are supplied alongside the archive.

Slack tools require a locally configured bot token. Hosted mobile relay,
OAuth distribution, and device pairing are not included. No model credentials
are bundled. Release verification used local mocks rather than paid completions
or real Slack messages.
